二、改造思路

核心目标：让智能开关一直通电（火+零），且只有一个开关直接控制灯（主控），另一个通过无线信号控制（副控）。

由于火线只在A、灯控线只在B，需要利用现成的 L1/L2 双联线 来"搬运"缺少的线。

三、选择接线方案

方案二：开关 B 做主控

方案说明

开关A有火线但无灯控线 → 需要从B"借"灯控线过来。利用L1传灯控线，L2传火线。

开关B通过无线控制，无需接线切换

接线步骤

  1. 开关A：火线接入 L 端子（不变）
  2. 开关A：火线同时短接到 L2 端子（火线经L2去B）
  3. 开关A：L1 端子接从B来的灯控线（最终控制灯）
  4. 开关B：将原本的 灯控线 改接到 L1 端子
  5. 开关B：L2 端子接从A来的火线（副控供电）
  6. 两个开关的零线保持原有接法不变

方案说明

开关B有灯控线 → 直接做主控。利用L1把A的火线"搬运"过来给B供电。

开关A通过无线控制，无需接线切换

接线步骤

  1. 开关A：将原本的 火线 从 L 改接到 L1（火线经L1去B）
  2. 开关B：L1 端子接从A来的火线（主控供电）
  3. 开关B：L 端子接原本的灯控线（直接控制灯）
  4. 开关B的L2端子闲置或封好
  5. 开关A的L端子闲置，L2端子闲置
  6. 两个开关的零线保持原有接法不变

四、核心要点 & 给师傅的提醒

不管选哪个方案，记住：主控开关必须同时有火线、零线和灯控线。副控开关只需要火线和零线（通过无线控制主控）。当火线与灯控线不在同一个开关盒时，就利用L1/L2双联线来"搬运"。

关键提醒

  • 智能开关必须同时接火线和零线，不能只接火线
  • 改造后其中一个开关盒里可能有两根火线，不要混淆
  • 接线前务必断电操作，用验电笔确认无电后再动手
  • 建议改造前先拍照记录原有接线，方便复原
  • 不确定哪个是灯控线？用验电笔测试：灯控线在灯关闭时没电，灯开启时有电
